■ RICOCHET ARCADE

Welcome to Ricochet Arcade for Android! This is a mobile port of the classic 2D physics-based arcade puzzle game, completely rebuilt from the C++ (SFML) original using modern web technologies (HTML5 Canvas & JavaScript) and wrapped into a native Android application using Capacitor.

■ RULES & GAMEPLAY

  • You control a paddle at the bottom of the screen.
  • Aim and bounce the ball to destroy the layout of targets (bricks) above.
  • The ball reflects off the walls, ceiling, and your paddle based on the angle of incidence.
  • Hitting a target destroys it and increases your score.
  • Clear all targets on the screen to complete the stage.
  • If the ball falls past your paddle — it's Game Over!

■ TOUCH CONTROLS

  • ◀ / ▶ buttons — tap and hold to move your paddle left or right.
  • Menu navigation — tap directly on PLAY, OPTIONS, or EXIT to select.

■ TECH STACK

  • GAME ENGINE
    Custom HTML5 Canvas Engine (Vanilla JS)
  • AUDIO ENGINE
    Web Audio API — procedural chiptune SFX & BGM
  • NATIVE WRAPPER
    Ionic Capacitor (Android Studio / Gradle)
  • ORIGIN
    Rebuilt from a C++ (SFML) original
